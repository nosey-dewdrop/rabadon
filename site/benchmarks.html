the suites it was run against

Twelve open-source projects, each pinned to a commit, each installed and taken green before anything was measured. Flake is the share of clean runs that came back red with no patch applied at all, which is the number that decides whether a red run may be treated as a verdict. Locked is how many test files the judge hashes before a proposer is allowed to touch the tree.

Eight of the twelve produced no red run at all on a clean tree. 4 did, and those four are the reason the arbiter re-samples a red before it is allowed to become a verdict: on a suite that flakes, a single red throws away a correct fix somebody already paid for.

what is still open

Four rounds of red-teaming this gate, 319 attempts, named 95 ways past it. One representative command each, judged by the binary this page describes: 37 refused, 58 allowed. They fall into four groups, and none of them is a surprise the code did not already suspect.

group open why 14 the deleting verb is not rm 14 find -delete, rsync --delete, truncate, dd, shred, a bare redirect. the law knows five verbs 5 the shell moved and nobody followed 5 pushd, cd -P, cd --. plain cd is followed; its options and pushd are not 11 the program is not on the line 11 bash s.sh, npm run deploy, python3 -c. three of them record a PARSE_LIMIT, the rest are silent 28 git has other ways to the same place 28 git push --forc (git accepts abbreviations), branch -D main, clean -xfd, reset --hard @{u}, rm -rf .git

Enforce mode IS on, and these are its published limits. This line used to read "enforce mode is not on, and this is the reason" — true when it was written, false from the day the switch was turned on, and left standing on a page nobody re-read. A claim about the machine that outlives the machine is the same defect this project measures in other people's numbers. The escapes stay published beside the refusals, because a gate that promises a protection it cannot hold is worse than one that says what it stops. Reproduce with python3 redteam/redteam.py; it judges and never runs, with every destructive binary shadowed on PATH and the log of what they were asked to do asserted empty.

what has not been measured

A quiet machine. Every run on this page shared its box with other work, so the wall-clock columns are contaminated and the pass or fail results are not. A second node version, to see whether the express flake follows the runtime. The date decay in date-fns, whose red rate climbs with the calendar. And the real test-file count in six of the twelve repositories, which leaves the question of how much of each suite the lock actually covers open in those six.
