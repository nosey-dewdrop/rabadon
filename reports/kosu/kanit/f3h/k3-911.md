# K3 — where the unexplained 911 us goes. MEASURED, not reasoned about.

2026-08-30, macOS 24.2.0, this machine. `reports/R7/accept.sh` was NOT touched,
NOT sourced, NOT re-run for these numbers. Its probe recipe (copy `gate.cpp`,
inject at the `main()` anchor, build `-O2`) is reproduced in
`reports/kosu/kanit/f3h/k3-911.sh` so the two instruments are the same one.

The gap the F3g verdict left standing: the shipped binary's leg 3
(`main` -> exit) profiled at **1031.5 us**, `accept.sh`'s `2b` probe — the same
leg, same flags — read **1942.8 us**. 911 us with no owner. Four phases each
blamed a different leg and the arbiter refuted all four, so nothing is blamed
here. One factor is removed at a time and whatever moves is the answer.

## FINDING 1 — 433 us of it is the daemon round trip `2b` switches on itself

`k3-paired.sh`, the two arms INTERLEAVED, R=8 rounds of N=120, machine state
shared:

    round 1  SOCK set 1272.2  unset  841.5  diff +430.7
    round 2  SOCK set 1343.5  unset  866.9  diff +476.6
    round 3  SOCK set 1381.0  unset  931.2  diff +449.8
    round 4  SOCK set 1427.5  unset 1010.6  diff +416.9
    round 5  SOCK set 1467.8  unset 1021.1  diff +446.7
    round 6  SOCK set 1514.4  unset 1078.8  diff +435.6
    round 7  SOCK set 1532.0  unset 1119.2  diff +412.8
    round 8  SOCK set 1585.7  unset 1172.0  diff +413.7

    median +433.1 us · min +412.8 / max +476.6 · ONE-SIDED 8/8 · |439 us| band: NOT beaten

**Talking to the daemon costs the gate 433 us MORE than not talking to it, on
this machine, in eight paired rounds out of eight.** R7 goal 2 built the daemon
to make the gate cheaper; measured here it does the opposite, and `2b` is the
only arm that runs with the socket exported, which is why `2b` reads high and a
profile of the shipped binary does not.

**AND THE NUMBER IS NOT CLAIMED AS A SPEEDUP.** 433.1 us does not exceed the
run's |439 us| band, so by this run's own rule (§3.8/4, DURUM.md) it is a
LOCATION, not a win. Nothing was changed to collect it. `2b` stays red and the
1000 us ceiling was not moved; `accept.sh` is not in this phase's diff.

## FINDING 2 — 265 us of it is the gate's own ledger growing under it

Fresh `$HOME` every round, no daemon, socket unset; the only thing that changes
between the two columns is 1500 more calls' worth of spool:

    round 1  after ~160 calls  792.1 us   after ~1660 calls 1066.5 us   (spool 392K)
    round 2  after ~160 calls  799.7 us   after ~1660 calls 1063.8 us   (spool 392K)
    round 3  after ~160 calls  823.0 us   after ~1660 calls 1056.9 us   (spool 392K)

**+265 us, 3 rounds out of 3, same sign, same size.** The gate's cost is not a
constant: it grows with how long the session has been running. `accept.sh`
takes its 300 samples after 60 warm calls plus everything the rest of the
script already spent, so part of the 911 us is simply that `2b` is measured
LATER in a session than a cold profile is. This has an owner nobody has named
yet and it is not this phase's card.

## What this makes of a cross-session comparison

Inside the single 8-round paired run above, the SOCK-unset arm drifted 841.5 ->
1172.0 us — **+39% with no code change at all.** So the 1942.8-vs-1031.5
comparison that produced "911 us" was taken across two sessions with two
fixtures and cannot be attributed to code. The two factors above are measured
and one-sided; the remainder is drift of that size, and it is written down as
drift rather than assigned to a leg.
